## Text Classification of Gym Reviews (DAT 402)

Explored whether written gym reviews could predict star ratings using supervised machine learning.

**Problem**  
Can review text be used to classify sentiment or rating category?

**Approach**  
- Text preprocessing and feature extraction (e.g., TF-IDF representation)
- Supervised classification models
- Train/test evaluation with performance comparison

**What this demonstrates**  
Ability to move from unstructured text → structured features → evaluated predictive model.

## Depression Screening Workflow Assessment (BMI 613)

Human factors analysis of a PHQ-2/PHQ-9 screening workflow in a primary care setting.

**Problem**  
Identify workflow breakdown points that reduce screening completion and follow-up reliability.

**Approach**  
- Workflow mapping  
- Hierarchical Task Analysis (HTA)  
- Structured evaluation plan for usability and process reliability  

**What this demonstrates**  
Structured systems thinking, evaluation design, and workflow analysis in healthcare contexts.
